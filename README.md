# ツケトリ

友人・家族・知人との間で発生したお金の貸し借りを、簡単かつ直感的に記録・管理できる Flutter 製モバイルアプリです。誰にいくら貸したか・借りたか、返済状況、相手ごとの残高をひと目で確認できます。

要件定義書に基づく **MVP（Minimum Viable Product）** を実装しています。

## 主な機能（MVP）

- **貸した／借りたの取引登録**（色と文言で明確に区別）
- **相手の登録・編集・非表示・削除**（連絡先メモ付き）
- **ホーム画面の残高表示**（現在残高／貸した総額／借りた総額／未返済／返済済み）
- **取引履歴**（検索・種別/ステータス/期間の絞り込み・並び替え・月別表示）
- **取引の詳細・編集・削除**（削除は確認ダイアログ付き）
- **返済の記録**（全額返済／一部返済／返済方法・返済日・メモ／過剰返済防止）
- **相手ごとの残高表示**と**貸し借りの相殺**（確認画面付き）
- **返済期限の設定**（期限なし／1週間後／1か月後／日付指定）と期限超過表示
- **統計画面**（期間別の数値カード・相手ごとの残高）
- **テーマ設定**（ライト／ダーク／端末設定に合わせる）

データはローカル（`shared_preferences`）に保存されます（要件 12.3：初期リリースはローカル保存を基本）。

## 技術スタック

- Flutter 3.29 / Dart 3.7
- 状態管理: `provider`
- 永続化: `shared_preferences`（JSON シリアライズ）
- フォーマット: `intl` / ID 生成: `uuid`

## プロジェクト構成

```
lib/
├── main.dart                 # エントリポイント・DIセットアップ
├── models/                   # ドメインモデルと計算ロジック
│   ├── person.dart
│   ├── transaction.dart      # 取引（残額・実効ステータスの導出を含む）
│   ├── transaction_type.dart # 貸した／借りた
│   ├── transaction_status.dart
│   ├── repayment.dart        # 返済・返済方法
│   └── balance.dart          # 残高・差額の集計（要件10章の純粋関数）
├── repositories/
│   └── app_repository.dart   # ローカル永続化
├── state/
│   ├── app_state.dart        # 取引・相手・返済のCRUDと集計
│   └── settings_state.dart   # テーマ設定
├── theme/                    # 配色・テーマ・ステータス色
├── utils/formatters.dart     # 金額・日付フォーマット
├── widgets/                  # 共通ウィジェット
└── screens/                  # 画面
    ├── root_shell.dart       # 下部タブ（ホーム／履歴／人／設定）
    ├── home/ history/ person/ transaction/ repayment/ stats/ settings/
```

## セットアップと実行

```bash
flutter pub get

# エミュレータ／実機で実行
flutter run

# Web で確認する場合
flutter run -d chrome
```

## テスト・静的解析

```bash
flutter test       # ユニット＋ウィジェットテスト
flutter analyze    # 静的解析
```

計算ロジック（残額・全体残高・相手差額・期限超過判定）、状態遷移（返済・過剰返済防止・相殺・永続化の復元）、および主要画面の描画・遷移をテストで検証しています。
