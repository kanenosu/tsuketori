# ツケトリ

友人・家族・知人との間で発生したお金の貸し借りを、簡単かつ直感的に記録・管理できる Flutter 製モバイルアプリです。誰にいくら貸したか・借りたか、返済状況、相手ごとの残高をひと目で確認できます。

要件定義書に基づく **MVP（Minimum Viable Product）** を実装しています。

## 主な機能（MVP）

- **貸した／借りたの取引登録**（色と文言で明確に区別）
- **相手の登録・編集・非表示・削除**（連絡先メモ付き）
- **ホーム画面の残高表示**（現在残高／貸した総額／借りた総額／未返済／返済済み）
- **取引履歴**（検索・種別/ステータス/期間の絞り込み・並び替え・月別表示）
- **取引の詳細・編集・削除**（削除は確認ダイアログ付き）
- **返済の記録**（全額返済／一部返済／返済方法・返済日・メモ／過剰返済防止）
- **相手ごとの残高表示**と**貸し借りの相殺**（確認画面付き）
- **返済期限の設定**（期限なし／1週間後／1か月後／日付指定）と期限超過表示
- **統計画面**（期間別の数値カード・相手ごとの残高）
- **テーマ設定**（ライト／ダーク／端末設定に合わせる）
- **ローカルJSONバックアップ・復元**（内容検証・置換前確認・取消・保存失敗時の保持）

データはローカル（`shared_preferences`）に保存されます（要件 12.3：初期リリースはローカル保存を基本）。

## 技術スタック

- 検証環境: Flutter 3.44.7 / Dart 3.12.2（同梱Dartを使用）
- 状態管理: `provider`
- 永続化: `shared_preferences`（JSON シリアライズ）
- フォーマット: `intl` / ID 生成: `uuid`

## ローカル保存と操作

- 履歴の検索欄で相手・メモ・金額を検索できます。金額順・返済期限順は全期間を通して並びます。
- 「人」の右上の非表示アイコンから非表示の相手を開き、メニューの「再表示する」で戻せます。非表示にしても取引・残高は残ります。
- 相手の電話番号・メールアドレス・メモは、編集欄を空にして保存すると消去できます。
- 台帳は `tsuketori.ledger.v1` の単一JSONとして保存します。従来の3キー形式は読み込み可能で、最初の保存成功時に移行します。旧キーは保持されますが、移行後の更新は新形式のみに書き込まれるため、旧アプリへの差し戻しでは新しい取引は見えません。
- 保存が失敗した場合は台帳の変更を戻し、入力画面で再試行できます。読み込み失敗時はデータを上書きせず再試行画面を表示します。
- `shared_preferences` はOSの強制終了・電源断時の耐久性を保証するデータベースではありません。設定からローカルファイルにバックアップできます。自動バックアップ・クラウド同期はありません。

## バックアップ・復元

設定の「データのバックアップ」または「データの復元」から操作します。

1. **ファイルに書き出す**: 非表示の相手を含む、相手・取引・返済の全件をJSONに保存します。Webではブラウザーのダウンロードとして保存されます。
2. **ファイルを選んで復元**: 形式・通貨・ID重複・参照先・日付・返済合計・残額・ステータスを検証します。
3. 作成日時・件数・残高を確認し、**置き換えて復元**を選ぶと現在の台帳全体を置き換えます。追加・結合ではありません。取消・不正ファイル・保存失敗時は現在の台帳を保持します。空のバックアップも、確認後は空の台帳へ置き換わります。

対応形式は `format: tsuketori.backup`、`version: 1`、`currency: JPY`、10MiB以下です。テーマ設定は含みません。ファイルは暗号化されず、氏名・連絡先・金額・メモが入るため、安全な保存先で管理してください。アプリから自動アップロードはしません。

保存データが壊れて起動できない場合は、読込失敗画面の「バックアップから復元」で復旧できます。旧内部保存JSONそのものはバックアップファイルとは別形式です。

ファイル選択には [file_picker 10.3.10](https://pub.dev/packages/file_picker/versions/10.3.10) を使用しています。

## 表示の意味

画面はiPhoneの標準アプリを参考に、グループ化した一覧と控えめな操作色で統一しています。ホーム右上の「＋」から取引を追加できます。ホームの「受け取る予定」「返す予定」は返済後の未精算額、「貸し借りの差額」はその差です。ライト／ダーク表示に対応しています。

- 相手詳細の「差額なし（未精算の取引あり）」は、未返済の貸し・借りが同額の状態です。全件精算済みとは区別します。
- 統計の上段は選択期間に取引日が含まれる貸付・借入の元金の差額です。返済による増減や現金収支ではありません。
- 統計の相手別残高は**全期間の現在残高**で、非表示の相手も含みます。差額ゼロの相手は表示しません。
- 未実装の通知ボタンは画面から除外しています。

Android確認用APK: `flutter build apk --debug`。ストア公開用の署名設定は別途必要です。
